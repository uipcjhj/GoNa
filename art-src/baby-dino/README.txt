Baby Dino Snack Adventure - starter pixel art assets

These PNGs are separated from the generated concept sheet using approximate background removal. Please inspect and refine edges before final release.

Place the public/assets folder inside your Claude Code project.

Core poses: dino-idle.png, dino-run-1..4.png, dino-jump.png, dino-happy.png.
Collectibles: strawberry.png, banana.png, donut.png, cookie.png, pudding.png, cupcake.png, star.png.
Background and obstacles are not included yet; ask Claude Code for pixel art placeholder shapes or create them later.
Use nearest-neighbor scaling in your game for crisp pixel art.
