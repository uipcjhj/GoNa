# 대표 타이틀 고나를 움직이게 하려면 필요한 그림

현재 대표 타이틀은 **B안**: 원본 그림을 그대로(정적으로) 쓰고, 그림 위에 폭포·반딧불·꽃잎·구름·버튼 반짝임만 얹습니다.
그림 속 고나를 오려내 움직이면 뒤를 메운 자국이 드러나므로 그 방식은 쓰지 않습니다.

고나를 실제로 움직이게(A안) 하려면 아래 **두 가지가 함께** 필요합니다.

## 1. 고나가 없는 배경
- `public/assets/title/parts/background-no-gona.png` — 원본과 같은 1448×1086, 고나 자리에 길·풀밭이 그려진 그림
  (로고는 있어도 되고 없어도 됨)

## 2. 대표 타이틀 고나 스프라이트 시트
- 파일: `public/assets/title/gona-title-sheet.png`
- 배경 투명 PNG, **같은 크기 프레임을 가로 한 줄로** (프레임 380 × 470 px, 발끝이 프레임 바닥)
- 그림체·색: 지금 타이틀 고나와 동일

| 번호 | 동작 |
| --- | --- |
| 0–3 | 대기: 숨쉬기 |
| 4 | 눈 감기 |
| 5 / 6 | 왼쪽 / 오른쪽 보기 |
| 7–12 | 걷기 한 주기 |
| 13–17 | 통통 뛰기 (웅크림 → 공중 → 착지) |

두 파일이 오면 배경을 1번으로 바꾸고, 그 위에 2번 고나를 독립 스프라이트로 올려 움직이게 하겠습니다.

## 3. 알 부화 장면 (선택)
지금은 게임 도트(둥지·알·갓난아기 3프레임)로 만들었습니다. 더 풍부하게 하려면:
- `public/assets/opening/newborn-hatch.png` — 갓난아기 고나 프레임 (32×32 내외, 가로 한 줄):
  앉기 / 눈 감기 / 왼쪽 보기 / 오른쪽 보기 / 기지개 / 하품 등 6~8장

# 스토리 프롤로그 내레이션 교체

- 위치: `public/assets/voice/prologue-01.mp3` … `prologue-10.mp3` (자막 1~10번 순서)
- 형식: mp3 (mono, 44.1kHz 권장), 앞뒤 무음은 짧게. 길이는 자유 — 문장 길이는 파일 길이에 맞춰 자동 조정
- 현재 파일은 AI 음성 합성(여성 프리셋 'Hana'). 성우 녹음으로 바꾸려면 같은 이름으로 덮어쓰면 됩니다.
- 괴물 실루엣을 정식 그림으로 바꾸고 싶으면: 뽀뽀괴물·킁카괴물 각각 투명 PNG(도트 46×54 정도, 눈은 따로)를 주시면 `src/art/prologueArt.ts` 대신 사용하도록 바꿀 수 있습니다.

# 보스전 그림 (지금은 코드로 그린 임시 도트)

넣으면 자동으로 교체됩니다 (없으면 지금 그림 유지).

| 파일 | 내용 |
| --- | --- |
| `public/assets/boss/kiss-sheet.png` | 뽀뽀괴물 시트: **같은 크기 프레임 3장을 가로 한 줄로** (권장 프레임 44×44px, 배경 투명, 발끝이 프레임 바닥, **왼쪽을 바라봄**) — 0 대기 · 1 통통(살짝 찌그러짐, 대기와 번갈아 재생) · 2 뽀뽀(입술 쭉, 공격·피격·쓰러짐에 사용) |
| `public/assets/boss/sniff-sheet.png` | 킁카괴물 시트: 같은 형식 (권장 프레임 48×46px) — 0 대기 · 1 코 흡입(콧구멍 벌렁) · 2 부풀기(냄새 폭발 직전·쓰러짐) |

- 게임 해상도가 작아서(세로 화면 폭 168px) 위 크기 정도의 도트가 가장 선명합니다. 큰 그림은 정수배(2×, 3×)로 그려 주시면 줄여서 맞출 수 있게 바꿔 드릴게요.
- 2페이즈(화남)는 코드에서 붉은 기를 입힙니다. 전용 프레임을 원하면 시트에 3~5번(2페이즈 대기·흡입·부풀기)을 더 붙여 주세요.
- 투사체(하트탄·냄새 구름·장판)와 필살기 이펙트는 지금 코드 도트로 충분히 보이지만, 원하면 같은 방식으로 PNG 교체를 추가할 수 있습니다.
- 보스전 전용 배경음악은 아직 없습니다(게임 음악 그대로). 원하면 `public/assets/audio/bgm-boss.mp3` 자리를 만들어 드릴게요.
