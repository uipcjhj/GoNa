    stripe   : 뒤로 낮게 묶은 짙은 갈색 머리 + 옆 앞머리, 둥근 얼굴, 베이지·크림 세로 줄무늬 블라우스, 연청바지
    glasses  : 넓은 어깨, 각진 얼굴, 굵은 검은 사각 안경, 헝클어진 짙은 갈색 머리, 어두운 갈색 무늬(카모풍) 셔츠, 청바지
    ponytail : 작은 체구, 이마가 드러나게 높이 묶은 검은 포니테일, 동그란 눈, 밝은 회백색 티셔츠, 진청바지
    blacktee : 키 크고 마른 체형, 가르마 탄 짧은 검은 머리, 곧은 굵은 눈썹, 검은 티셔츠(작은 흰 로고), 짙은 회색 바지
    curly    : 작고 통통한 체형, 턱까지 오는 풍성한 곱슬 파마, 둥근 볼, 분홍 티셔츠 + 회색 소매, 남색 바지
    grey     : 할아버지 체형(둥근 배), 짧은 회색 머리(정수리·이마 위 숱 적음), 웃는 눈가 주름, 흰 헨리넥 셔츠, 갈색 바지
