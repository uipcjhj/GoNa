## 4. 필요한 에셋 (고해상도 투명 PNG, 지금 디자인 그대로)
- 인물별 캐릭터 원본: 고나 + 가족 6명, 투명 배경 PNG, 손실 압축 없이, 인물당 최소 160px 이상(또는 도트 1칸이 정수 px 인 진짜 도트 원본)
- 동작 프레임: 고나 달리기(감속·멈춤 포함)·올려다보기·눈 감고 웃기·간지러워하기·뒷모습 / 엄마 무릎 굽혀 팔 벌리기·안기(팔 레이어와 몸통 레이어를 따로) / 할머니 고개 기울여 볼뽀뽀(접근·닿기·떼기) / 삼촌 고개 숙여 킁킁(숙이기·킁킁 2~3·들기)
- 채팅에 이미지로 붙이면 줄어들거나 다시 압축될 수 있어, 원본 파일(PNG/ZIP)을 파일로 올리거나 저장소의 `art-src/ending/sprite-sheet/` 에 넣어 주면 가장 확실함

| 항목 | 결과 |
|---|---|
| 해상도 · 형식 | 1536x1024 PNG (무손실), RGBA |
| 투명 배경 | **아님** — 알파가 1~252 사이로 전체에 걸쳐 있음. 캐릭터 뒤에 반투명 유리판(알파 약 130~250)과 흰 후광이 그림 속에 붙어 있음 |
