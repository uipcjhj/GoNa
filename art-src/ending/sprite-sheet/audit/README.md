# 엔딩 캐릭터 화질·동작 에셋 점검 (작업 중단 보고)

## 1. 지금 엔딩 캐릭터의 원본과 추출 과정
- 원본: `art-src/ending/sprite-sheet/ending-characters-sheet.webp` — **1125x750 WebP (손실 압축)**, 받은 이미지 하나뿐
- 캐릭터 한 명 크기: 가족 약 40x55px, 고나 약 38x45px
- 추출(`tools/extract_ending_sprites.py`): 확대·축소·재압축 없음. 시트 픽셀 그대로 떼어 내고 반투명 가장자리만 켜기/끄기 → 추출 과정에서 생긴 손실은 없음
- 측정 (불투명 픽셀 기준)

| 그림 | 색 수 | 번진 경계 비율 |
|---|---|---|
| 게임 고나 4단계 (진짜 도트 48x45) | 920 | 0.39 |
| 게임 고나 3단계 (진짜 도트 33x34) | 277 | 0.30 |
| 시트 고나 기본 (38x45) | 1068 | 0.55 |
| 시트 엄마 기본 (39x55) | 1274 | 0.54 |

→ 시트 자체가 큰 그림을 부드럽게 줄인 뒤 손실 압축한 저해상도 이미지. 화면에서 1px 을 약 7 기기 픽셀로 키우므로 번짐이 그대로 보임.
- 렌더링 쪽 점검: Phaser `pixelArt: true`(nearest) · 스프라이트 좌표 정수 반올림 · 정지 장면 카메라 배율 정수 · 캔버스 CSS `image-rendering: pixelated`.
  확대 중(줌 이동 중) 배율은 잠깐 소수 · 캔버스(840px)를 화면(iPhone 1170 기기px)에 약 1.39배로 맞춤 — 픽셀 폭이 고르지 않을 수는 있으나 번짐의 주원인 아님 (배경은 같은 경로로 또렷)

## 3. 포옹·뽀뽀·킁카 동작 프레임 실재 여부 (엔딩 스프라이트 시트 기준)
| 필요한 동작 | 있음 | 없음 |
|---|---|---|
| 고나 달리기 | 4프레임 | 감속·멈춤, 올려다보기 |
| 고나 표정 | 기쁨 3 · 놀람 3 · 앉기 2 · 안기(두 팔 뻗기) 3 | 눈 감고 웃기, 간지러워하기, 뒷모습 |
| 엄마 포옹 | 두 팔 벌리기 3 | **무릎 굽히기, 고나를 감싸 안은 그림, 팔 레이어 분리** (시트의 '포옹 조합 예시'에 엄마·아빠는 없음) |
| 할머니 뽀뽀 | 손 뽀뽀(옆모습) 3 · 고나와 볼 맞대 안은 조합 그림 1장 | **고개 기울이기, 입이 볼에 닿는 프레임** |
| 삼촌 킁카 | 서서 냄새 맡는 얼굴 3 · 고나를 안은 조합 그림 1장 | **고나 머리 쪽으로 고개 숙이기, 킁킁 고개 움직임** |
| 포옹 조합 예시 | 이모·할머니·삼촌·할아버지 각 1장 (정지 그림) | 엄마·아빠, 조합의 동작 프레임 |

## 4. 필요한 에셋 (고해상도 투명 PNG, 지금 디자인 그대로)
- 인물별 캐릭터 원본: 고나 + 가족 6명, 투명 배경 PNG, 손실 압축 없이, 인물당 최소 160px 이상(또는 도트 1칸이 정수 px 인 진짜 도트 원본)
- 동작 프레임: 고나 달리기(감속·멈춤 포함)·올려다보기·눈 감고 웃기·간지러워하기·뒷모습 / 엄마 무릎 굽혀 팔 벌리기·안기(팔 레이어와 몸통 레이어를 따로) / 할머니 고개 기울여 볼뽀뽀(접근·닿기·떼기) / 삼촌 고개 숙여 킁킁(숙이기·킁킁 2~3·들기)
- 채팅에 이미지로 붙이면 줄어들거나 다시 압축될 수 있어, 원본 파일(PNG/ZIP)을 파일로 올리거나 저장소의 `art-src/ending/sprite-sheet/` 에 넣어 주면 가장 확실함
