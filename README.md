# 🦖 GONA’s Food Adventure

모바일 브라우저에서 바로 즐기는 따뜻한 레트로 도트 감성의 횡스크롤 러너 게임입니다.
**Vite + TypeScript + Phaser 4** 로 만들었고, 그림·효과음·배경음악은 모두 코드로 생성되어 별도 리소스 없이 실행됩니다.

## 게임 방법

| 조작 | 동작 |
| --- | --- |
| 화면 아무 곳이나 터치 | 점프 |
| 공중에서 한 번 더 터치 | 더블 점프 (빙글 회전!) |
| ⏸ 버튼 / 앱 전환 | 일시정지 (터치하면 계속) |
| 🔊 버튼 | 소리 켜기/끄기 |
| (PC) Space / ↑ / P | 점프 / 일시정지 |

- 🍓 딸기 10점 · 🍌 바나나 20점 · 🍪 쿠키 30점
- 바위에 부딪히면 ❤️ 1개 감소 (잠깐 무적), 3개를 모두 잃으면 게임 오버
- 시간이 지날수록 빨라지고 장애물 패턴이 다양해집니다
- 높은 곳의 간식은 더블 점프로만 먹을 수 있어요
- 최고 점수는 브라우저(localStorage)에 저장됩니다

## 실행

```bash
npm install
npm run dev        # 개발 서버 (같은 Wi-Fi의 폰에서 표시된 Network 주소로 접속)
npm run build      # dist/ 에 배포용 정적 파일 생성
npm run preview    # 빌드 결과 미리보기
npm run build:single  # dist-single/index.html 한 파일짜리 빌드 (어디든 올려서 실행)
```

## 오프닝(타이틀) 화면

게임 실행 → **알 부화 이야기**(자막이 한 글자씩, 음성 없음) → **움직이는 타이틀** → '게임 시작' → 1단계.

움직이는 타이틀은 오프닝 에셋 4장(`art-src/title4/`)으로 만듭니다. `python3 tools/build_title4.py` 가
알파 정리(0/255) · 시트에서 포즈·소품 분리 · 같은 도트 격자로 축소 → `public/assets/title4/*.png` + `src/ui/title4-layout.json`.

| 레이어 (아래→위) | 파일 | 움직임 |
| --- | --- | --- |
| ① 배경 | `bg.png` (941x1672 → 235x418 도트) | 정적. 가로 화면 양옆은 미리 흐리게 만든 `bg-side.png` |
| ② 고나 | `gona-walk1/2 · surprise · net · eat · trot.png` (포즈 시트에서 몸통만, 발끝 정렬) | 걷기 → 나비 발견 → 잠자리채로 쫓기 → 놓치고 뒤돌아봄 → 열매 발견·먹기 → 총총 (약 20초 반복) |
| ③ 곤충·과일 | `butterfly-0/1.png`(날갯짓 2장) · `fruit.png` | 나비는 고나 앞에서 팔랑 → 위로 도망 |
| ④ 버섯·덩굴·잎 | `mushrooms · vines · petal-*.png` (가로: `stone.png` 도) | 덩굴 1도트 살랑 · 꽃잎 떨어짐 |
| ⑤ 로고 | `logo.png` | 정수 배율, 양옆 최소 20px 여백 (작은 화면은 위 버튼 아래로) |
| ⑥ 버튼 · ⑦ 자막 | HTML (`ui/cover.ts`, `ui/subtitles.ts`) | 실제 버튼 / 텍스트 타이핑 |

- 코드: `src/ui/titleScene.ts` (그림·움직임), `src/ui/cover.ts` (버튼·배치)
- **선명함·떨림 방지**: 모든 그림은 같은 도트 격자를 **정수 배율 + nearest** 로만 그리고, 캔버스 크기 = 기기 픽셀 그대로. 위치는 정수 도트로만 이동(transform). 회전·확대 애니메이션·실시간 이미지 처리 없음
- **성능**: 그림은 앱 시작 때 미리 읽어 둠. 고나·나비 캔버스는 포즈가 바뀔 때만 다시 그림. 타이틀이 화면을 덮는 동안 뒤의 게임(Phaser) 그리기를 쉼(`game.loop.sleep`) → 시작 버튼 누르면 즉시 다시. 타이틀이 안 보이면 애니메이션 루프도 멈춤
- 예전 정적 타이틀(`art-src/title/` · `tools/build_cover_layers.py`)은 그림 원본만 남겨 둠

## 캐릭터 이미지 교체

1. 도트 이미지를 `public/assets/character/dino.png` 로 저장
   - 프레임을 가로로 이어 붙인 PNG: `[달리기1][달리기2][점프]`
   - 한 장짜리 이미지도 가능 (달릴 때 통통 튀는 효과로 대체)
2. 필요하면 `src/config.ts` 의 `CHARACTER_ASSET` 수정
   - `frameCount` 시트 안의 프레임 수
   - `runFrames`, `jumpFrame` 프레임 번호
   - `displayHeight` 화면에서의 캐릭터 높이(px)
   - `titleFrame` 타이틀에서 보여줄 프레임, `blinkFrame` 눈 감은 프레임 (-1 이면 깜빡임 없음)

현재는 직접 제작한 아기 공룡 도트(`art-src/baby-dino/`)를 `tools/build_dino_sheet.py` 로
1:1 도트 시트로 변환해 `public/assets/character/dino.png` 에 넣어 두었습니다
(대기·달리기 4프레임·점프·눈 감기·기쁨·놀람). 원본을 고쳤다면 `python3 tools/build_dino_sheet.py` 로 다시 만드세요.

파일이 없으면 코드로 그린 기본 캐릭터(물방울 모양 갈색 머리, 동그란 얼굴, 연두색 공룡 옷)가 나옵니다.
기본 캐릭터 도트는 `src/art/sprites.ts` 의 `DINO_FRAMES` 에서 글자 단위로 직접 고칠 수도 있어요.

## 보스전 (뽀뽀괴물 · 킁카괴물)

```
1단계 갓난아기 → 2단계 기어 다니는 고나 ─(게이지 가득)→ ⚔ 뽀뽀괴물 ─(승리)→ 3단계 직립보행
→ 4단계 자이언트 곤룡 고나 ─(게이지 가득)→ ⚔ 킁카괴물(최종) ─(승리)→ 엔딩
```

- 수치는 모두 `src/game/boss.ts` (보스 체력·피해량·쉬는 시간·필살 충전·방패·HP)
- **보스전 체력**: 하트 3개 + 하트마다 HP 100. 맞으면 HP 만 깎이고, 0 이 되면 하트 -1 → 남은 하트가 있으면 HP 100 (넘친 피해는 버림). 맞은 직후 0.7초·하트 잃은 직후 1.5초 무적. 일반 달리기는 기존대로 바위 = 하트 1개
- **조작**: 화면 빈 곳 터치 = 점프(공중에서 한 번 더 = 더블 점프) · 왼쪽 아래 **방패**(1초 방어, 4초 재사용) · 오른쪽 아래 큰 **공격**(머리카락 부메랑, 돌아오기 직전에 누르면 돌아오자마자 발사) · 그 옆 **필살**(100%에서)
- **분노 4단계**: 일반 → 1차 분노(HP 70%) → 2차 분노(40%) → 최종 분노(15%) → 패배. 단계가 바뀔 때마다 표정·오라·색·공격 패턴·음악이 바뀜
- **보스 필살기 최소 3회**: 분노 단계마다 첫 공격이 필살기(① ② ③). 그 단계의 필살기를 보여 주기 전엔 다음 단계(또는 패배)로 넘어가지 않음 — 무적이 아니라 피해는 그대로 들어가고, 필살기는 그 단계 첫 공격이라 곧바로 나옴. 최종 분노에선 4번째 공격마다 ③ 다시. 필살기 뒤엔 지쳐서/기절해서 반격 시간(1.5~2배 피해). 모두 점프 또는 방패로 피함
- **뽀뽀괴물**(튜토리얼, 체력 28): 하트탄 20 · 돌진 30 · 뽀뽀 파동 25 · 왕뽀뽀 35. 필살기 ① 초대형 왕뽀뽀 ② 왕뽀뽀 + 작은 하트 연발 ③ 왕뽀뽀 2연속 + 하트 폭풍(가장 화려). 분노할수록 하트가 조금 빨라짐. 두 번째 공격 뒤 머리카락 부메랑 각성
- **킁카괴물**(최종, 체력 40): 냄새탄 25 · 흡입 후 충돌 30 · 냄새 폭발 35 · 냄새 장판 20 · 파동 35. 필살기 '돼지코 군단' — 분홍 돼지코(콧구멍 2개, 3프레임: 보통·킁! 부풂·쭈욱 납작) 여러 개가 보스 코에서 튀어나와 킁킁(수축·팽창 · '킁!') 고나 쪽으로 고개를 돌리고, 나뭇잎이 빨려 듦 → 땅을 따라 오는 냄새 파동
  - 돼지코 **돌진**: 예고 0.55초(땅 높이로 내려와 부르르 '킁!' + 빨간 화살표) → 고나를 향해 빠르게 돌진(점프·방패, 부메랑으로 부술 수 있음) → 피하면 화면 끝 땅에 '쾅' 부딪혀 픽셀 폭발
  - ① 킁킁 탐지! (돼지코 2개 개별 돌진) ② 돼지코 대소동! (4개 연속 돌진, 점점 빠르게 · 도착 간격 1.05초) ③ 초특급 킁카 폭풍! (황록 회오리·강한 흡입·냄새 폭발 → 작은 코 2개 → 마지막 거대 돼지코가 가장 빠르게 → 에취! 재채기하며 기절)
  - **코 약점**: 필살기 뒤 지쳤을 때 코 중앙에 황금 과녁 → 그동안 부메랑(기존 공격 버튼)이 코를 노리고, 코에 맞으면 2배 피해 · 코가 찌그러지고 눈 찡그리며 밀려남 · '약점 명중! ×2'. 과녁이 사라지면 보통 피해, 놓쳐도 처치 가능 (단계별 필살기 보장은 그대로)
  - 파동 도착 간격 1초 이상(한 번씩 점프) · 돼지코는 최대 5개를 만들어 재사용 · 필살 게이지 절반 속도

- **일반 몬스터** (`src/game/monsters.ts`, 3단계부터 = 뽀뽀괴물을 이긴 뒤): 둘 다 화면 오른쪽에서 들어와 **고나 쪽으로 계속 천천히 다가옴**. 처치하지 못하면 부딪혀 HP -25 (천천히 다가오므로 점프로 넘기보다 부메랑으로 처치)
  - **이름표**: 머리 위에 작은 픽셀 글씨 **[화학과안경잽이]** · **[방구할배]** (따라 움직이고 화면 위로 잘리지 않음, 처치되면 같이 사라짐)
  - **돌진** (`MONSTER_DASH`): 두 번째 공격부터 가끔(35%) — '!' + 0.7초 예고(안경잽이: 안경 번쩍 + 몸을 뒤로 젖힘 / 방구할배: 배를 내밀고 한 번 출렁) → 0.45초 짧고 빠르게(115px/s) 돌진 → 안경잽이는 비틀비틀 숨 고르기, 방구할배는 바로 엉덩이를 내밀고 방귀(엉덩이에서) → 능청 웃음 → 다시 천천히. 점프로 넘거나 부메랑으로 처치. 보스전에는 일반 몬스터 없음
  - 화학과안경잽이(HP 2): 안경 번쩍 + 보라 물약 플라스크를 꺼내 듦(예고) → **플라스크 2~3개를 포물선으로 '휙!'**(0.75초 간격, 던지는 동안에도 다가옴). 고나 앞 4~26px 에 떨어지며 유리가 '팡!' 깨지고 보라 웅덩이가 1.6초 퍼짐 (플라스크 맞으면 HP -20 · 웅덩이 밟으면 HP -15) → 점프로 피하기 / 부메랑으로 공중에서 깨기(웅덩이 없음). 그림: 넓은 바닥·좁은 목·코르크·보글보글 거품·작은 해골 표시 12x16 (`flaskSheet` · `shatterSheet` · `puddleSheet`)
  - 방구할배(HP 3 · 생김새는 배불뚝이 중년 아저씨 그대로): 멈춤 → 엉덩이 뒤로 쭉 → 씰룩 → **엉덩이에서 '뿡' 팡!**(충격선) → 황록 독구름(짙은 초록 음영 · 냄새 줄)이 부풀어 고나 쪽으로 → 능청스러운 표정 → 다시 다가옴. 가까울수록 자주
  - 그림: 코드 도트(`src/art/monsterArt.ts`) — 정식 PNG 는 `public/assets/monsters/{glasses,farter}-sheet.png`
- **바위**: 점프로 피하는 장애물. 부메랑은 바위를 그대로 통과(깨지지 않음 · 점수·필살 게이지 없음)
- **버튼**: 1·2단계 = 화면 터치(점프·더블 점프)만 · 3·4단계 = + 부메랑 공격 버튼 · 보스전 = + 방패 · 필살. 보스전이 끝나면 방패·필살 버튼이 살짝 사라지고 입력도 꺼짐
- **달리기 속도** (`src/config.ts` SPEED): 시작 110px/s. 20초마다 배율 +3%(1·2단계) / +5%(3·4단계), 단계별 하한~상한 ×1.0~1.15 · ×1.1~1.3 · ×1.3~1.6 · ×1.5~1.85(최고 약 203px/s). 보스전은 110 고정 → 끝나면 원래 속도로 부드럽게. 이어하기는 그 단계 하한부터. 장애물 간격·몬스터 투사체는 속도에 비례
- **고나 아파! 표정** (`src/art/hurtFace.ts`): 각 성장 단계의 원래 그림(같은 포즈·크기)에서 눈을 '> <' 로 찡그리고 울상 입·진한 볼, 머리카락 흔들림 2장을 앱 시작 때 미리 만듦. 맞으면 0.5초 표정 + 움찔 + 살짝 뒤로 밀림 + 은은한 깜빡임
- **필살 게이지**: 일반 스테이지에서 몬스터를 잡아 모은 게이지는 다음 보스전으로 이어짐
- **보스 분노**: HP 100~71% 일반 · 70~36% 1차 분노 · 35~0% 2차 분노. 전환 때 1.5초 멈추고 화난 얼굴·김·경고 문구·전용 효과음
  - 필살기 공통: 약 1.5초 예고(화면 어둡게 · 보스만 밝게 · 오라 고리 · 차오르는 소리) → 발동 때 색 번쩍 + 짧은 흔들림 + 쾅 → 맞으면 강한 충격·파편 → 지침/기절. 도트는 `src/art/specialArt.ts` 에서 미리 만들고, 파티클은 필살기마다 약 10개 이하
  - 뽀뽀괴물 (HP 28, 전투 약 1~2분): 일반(느린 하트탄·짧은 돌진) → 1차(하트탄 2연속·통통 자리 바꾸기·분홍 오라) → 2차(**초대형 왕뽀뽀**: 크게 부풀고 분홍 오라 → 화살표 길 예고 → 일반 하트탄의 약 4배 거대한 하트 + 도는 작은 하트 4개 + 하트·반짝이 꼬리(판정은 22x20 그대로), 점프·방패 / 뒤에 2.2초 지침 ×1.5 피해)
  - 한 번의 큰 피해(필살기 등)로 분노 단계를 건너뛰지 않음 (다음 문턱까지만 깎임). 뽀뽀괴물은 2차 분노에서 왕뽀뽀 → 지침(약점)을 보여 주기 전엔 HP 1 에서 버팀(약 4초, 맞으면 숫자는 그대로 표시)
  - 킁카괴물: 일반(냄새탄·코 흡입) → 1차(흡입 범위·힘↑·냄새탄 5발·짧은 장판·폭발) → 2차(**초강력 킁카 폭풍**: 숨 들이마시며 몸·코가 부풀고 황록 회오리 · 나뭇잎·먼지가 빨려 들어감 · 바람 화살표 · 고나 발밑 초록 '여기서 점프!' 안전 구간 → 강한 흡입(계속 점프) → 초대형 냄새 파동(그림 2.4배, 판정 그대로) → 2.6초 기절, 코 약점 ×2)
- **성장 필요량**: 1→2단계 18(기존 12) · 2단계→뽀뽀괴물 40(20) · 3→4단계 60(30) · 4단계→킁카괴물 60(30). 중간 즐길 거리: 별 젤리(새 간식, 50점·성장 +4) · 45~65초마다 '간식 비' 이벤트 · 일반 몬스터
- **체크포인트** (`src/game/checkpoint.ts`): 뽀뽀괴물 승리 → '3단계부터' / 킁카괴물전 진입 → '최종 보스부터'. 게임 오버·타이틀에서 '💾 이어하기', 따로 '새 게임'. 엔딩을 보면 지움. 최고 점수 기록은 그대로

## 성능 측정 (끊김 확인)

- **오프닝 구간별 기록**: 주소 끝 `?perf` (예: https://uipcjhj.github.io/GoNa/?perf) 로 열고 이야기를 보면 왼쪽 위에 `[오프닝 n/10] max … · >50ms …`. '복사' 를 누르면 구간별 표(오프닝 대기 · 오프닝 1~10 · 타이틀 · 게임: 프레임 수 · 평균 · 95% · 최대 · 25/50/100ms 넘는 프레임 수)가 함께 복사됨
- 프롤로그 첫 터치 멈칫 원인이던 효과음 `<audio>` 54개(시작 때 내려받기 + 첫 터치 때 전부 재생→정지)는 Web Audio 가 안 될 때만 만듦 (시작 때 mp3 요청 56 → 2)

- 켜기: 타이틀 🧪 → '성능 표시 켜기' (또는 주소 끝 `?perf`). 화면 왼쪽 위에 FPS · 평균/95%/최대 프레임 시간 · 최근 끊긴 프레임(25ms 이상) 목록
- 끊긴 프레임마다: `s`=게임 계산, `r`=그리기, 그리고 그 프레임에 있었던 일(버튼·점프·효과음 `sfx:jump` / 파일 재생이면 `(파일)` · `audio:unlock` 등과 걸린 ms)
- '복사' 버튼 → 기록 전체를 클립보드로 (아이폰에서 메모에 붙여 넣어 보내 주시면 원인 분석 가능)
- 계속 느리면 자동 '저사양 모드'(먼지 꼬리 끄기·반짝이 절반)
- 보스 그림: 지금은 코드 도트(`src/art/bossArt.ts`). 정식 그림은 `art-src/opening/ASSETS_NEEDED.md` 참고

### 안정화 메모 (실기기 끊김·잔류·몬스터)

- **스크롤 떨림**: 배경·땅·간식·몬스터 좌표를 정수 논리 픽셀(= 캔버스 5px 단위)로 반올림하던 것을 1/5 논리 픽셀(= 캔버스 1px)로 → 프레임마다 5px/10px 로 번갈아 움직이던 떨림 제거, 도트 선명도 그대로
- **매 프레임 비용**: 하늘(Graphics 5000+ 명령)을 매 프레임 다시 그리던 것 → 텍스처 1장, 떠오르는 점수 글자 텍스처 캐시, 숨은 점수 글자 갱신 제거
- **보스 잔류**: 모든 보스 연출 오브젝트는 `BossBattle.fx()` 로 등록되고 `cleanupCombat()` 이 승리·패배·재시작·씬 전환 때 공통으로 지움
- **일반 몬스터**: 3단계 이후 일정 시간(3단계 14초 · 4단계 10초) 안 나오면 다음 패턴에 반드시 등장. 대기 위치는 화면 안으로 제한
- **개발용**: 타이틀 🧪 → '몬스터 테스트 (3단계)' — `npm run dev` 또는 주소에 `?dev` 가 있을 때만 보임 (정식 플레이에선 숨김)
- **타이틀·프롤로그 고나**: 도트 그림을 확대·축소·회전하는 연출을 쓰지 않음(재샘플링 = 미세 떨림). 타이틀 고나를 실제로 움직이려면 `art-src/opening/ASSETS_NEEDED.md` 의 두 파일(고나 없는 배경 + 투명 스프라이트 시트)이 필요
- 측정: `perf.costs()` (프레임당 게임 계산·그리기 ms 평균)

간식을 먹으면 **점수**와 **성장 게이지**가 각각 오릅니다 (서로 독립). 게이지가 가득 차면 진화!

단계별 그림은 컨셉 시트에서 `python3 tools/build_growth_sprites.py` 로 만듭니다. 파일이 없으면 `dino.png` 포즈를 조합한 임시 애니메이션으로 동작합니다.

- 게이지 증가량: 딸기 1 · 바나나 2 · 쿠키 3 (`src/game/growth.ts` → `SNACK_GROWTH`)
- 진화 연출: 게임 정지 → 반짝이 + 이전/새 모습이 번갈아 바뀌며 크기·자세 변화 → 새 단계 이름 표시 → 1초 무적과 함께 재개
- 충돌 판정(`hitbox`)과 조작(`controls`: 점프 배율·최대 점프 수)은 단계별로 따로 설정 가능 — 지금은 모든 단계가 기존과 동일

- 향후 확장 구조(아직 게임에 연결 안 됨): `src/game/stages.ts`(스테이지), `src/game/boss.ts`(뽀뽀괴물·냄새괴물), `src/game/weapons.ts`(머리카락 부메랑)
