# 성장 단계별 캐릭터 그림

현재 `newborn.png`, `crawler.png`, `bigbaby.png` 는 `tools/build_growth_sprites.py` 가
컨셉 시트(`art-src/growth/gona-growth-concepts.png`)의 단계별 큰 그림에서 도트 격자를 복원해 만든 1:1 도트 시트입니다.
(잔디 받침·꽃·반짝이는 외곽선 바깥 채우기로 제거, 애니메이션 프레임은 기준 포즈의 도트를 옮기기만 해서 생성 — 새로 그리지 않음)
3단계 직립보행은 기존 `dino.png` 달리기를 유지합니다.

| 파일 | 프레임 | 애니메이션 |
| --- | --- | --- |
| `newborn.png` 25×20 ×3 | 0 엎드림 · 1 꿈틀(몸 1칸 늘림) · 2 눈 깜빡 | 꼬물꼬물 (+좌우 흔들림) |
| `crawler.png` 30×27 ×2 | 0 기기 · 1 앞뒤 다리 벌림 | 네 발 기어가기 |
| `bigbaby.png` 48×45 ×3 | 0 서기 · 1 왼발 들기 · 2 오른발 들기 | 묵직한 걸음 (+쿵쿵 통통) |

모두 1.2배(도트 1칸 = 6px)로 표시되어 기존 고나와 도트 크기가 같습니다.

## 직접 그린 그림으로 바꾸기 (선택)

여기에 PNG 를 넣으면 그 성장 단계는 자동으로 이 그림을 사용합니다.
없으면 기본 `dino.png` 시트의 포즈로 만든 임시 애니메이션을 씁니다.

| 파일 | 단계 | 기본 프레임 구성 (`src/game/growth.ts` → `STAGE_ASSETS`) |
| --- | --- | --- |
| `newborn.png` | 1. 갓난아기 고나 | 4프레임: 꼬물꼬물 0~3 |
| `crawler.png` | 2. 기어 다니는 고나 | 4프레임: 기어가기 0~3 |
| `walker.png` | 3. 직립보행 고나 | 6프레임: 달리기 0~3, 점프 4, 대기 5 |
| `bigbaby.png` | 4. 빅베이비 곤룡 | 6프레임: 달리기 0~3, 점프 4, 대기 5 |

- 프레임을 가로로 이어 붙인 투명 PNG, 오른쪽을 바라보는 그림
- 머리카락·얼굴·눈·옷 색은 기존 고나와 같게 유지해 주세요
- 프레임 수·번호가 다르면 `STAGE_ASSETS` 의 `frameCount`, `anim` 만 고치면 됩니다
- 그림 크기와 상관없이 충돌 판정은 `GROWTH_STAGES[].hitbox` 로 따로 관리됩니다
