# 타이틀(오프닝) 이미지 넣는 곳

| 파일 | 필수 | 설명 |
| --- | --- | --- |
| `title-bg.png` | 선택 | 오프닝 배경 그림 (16:9 추천, 예: 480×270 / 640×360 도트 원본). 글자·버튼은 넣지 마세요. |
| `title-fg.png` | 선택 | 배경 앞에서 살랑살랑 흔들릴 장식(잎 등). 투명 PNG, `title-bg.png` 와 같은 크기 |
| `logo.png` | 선택 | 제목 로고 이미지. 없으면 돌판 글자 로고 사용 |

파일이 없으면 코드로 그린 기본 버섯숲 배경이 나옵니다.
배경은 화면 비율이 달라도 잘리지 않고 전체가 보입니다.
캐릭터가 서는 위치는 `src/config.ts` 의 `TITLE_LAYOUT` 에서 조절합니다.
