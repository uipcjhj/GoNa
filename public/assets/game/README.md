# 게임 플레이 배경 이미지

- `game-bg-loop.png` (772×460): 원본 배경(`art-src/game-bg/gona-background-original.png`, 640×360)을
  끊김 없이 반복되도록 만든 이미지. `python3 tools/build_game_bg.py` 로 다시 만들 수 있습니다.
  - **연결 구간 (132px)**: 원본 오른쪽 끝 → 왼쪽 끝 사이를 원본의 숲·하늘·풀밭 조각으로 이어 붙임
    (블렌딩 없이 색 차이가 가장 적은 경로로 픽셀 단위로 잘라 이음, 폭포·동굴·모닥불 등 주요 그림은 재료에서 제외)
  - **잘린 큰 버섯 갓**: 기둥 중심 기준으로 대칭인 외곽선 모양만 계산해 닫고, 안쪽은 원본 왼쪽(그늘) 픽셀로 채움
  - **경계 덤불**: 원본의 잎사귀 덤불을 외곽선째 떼어 경계 앞에 배치
  - **숲 지붕 (위 100줄)**: 세로 화면에서 배경을 덜 확대할 때 위쪽을 채우는 나뭇잎 (가로 화면에선 화면 위로 숨음)
  - 원본의 버섯·폭포·동굴·나무·깃발·엄니는 그대로 (좌우 반전 없음)
- 파일이 없으면 코드로 그린 버섯숲 배경(`src/art/gameBg.ts`)이 나옵니다.
- 설정: `src/config.ts` → `GAME_BG`
  - `groundRow` 게임 땅과 맞닿는 줄 (400 = 원본 300줄 + 숲 지붕 100줄)
  - `portraitScale` 세로 화면 배경 배율 (기본 0.52, 작을수록 넓게)
  - `scroll` 배경 이동 속도 (땅 = 1, 기본 0.3) / `haze` 옅은 안개 (기본 0.3)
- 비교 이미지: `art-src/game-bg/loop-before-after.png`, `art-src/game-bg/mobile-before-after.png`
